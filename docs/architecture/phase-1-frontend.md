# Maths Mafia — Phase 1 frontend

## Intent
Build a complete, responsive frontend for a CBSE Class 10 Mathematics learning platform. This phase is limited to product design, UI, navigation, responsive layouts and client-side demonstrations.

## Boundaries
- Independent Maths Mafia identity. VAANI names, characters, artwork and assets do not belong in this project.
- No backend, database, authentication, payments or real student tracking.
- All dashboard metrics, practice questions, profile details and leaderboard records are sample data.
- The owner will provide study notes, questions and PYQs later.

## Design direction
Warm off-white canvas, deep ink navigation, violet primary accent and lime highlights. Use spacious layouts, considered typography, clear hierarchy, restrained gradients and geometric mathematics-inspired illustration. Avoid generic mascot art and remote asset dependencies.

## Routes
/, /dashboard, /learn, /learn/[slug], /practice, /tests, /library, /progress, /leaderboard and /profile.

## Interactions
Responsive mobile navigation, global page search, light/dark theme toggle, chapter search and category filter, sample multiple-choice quiz with answer explanations and results.

## Quality
Strict TypeScript, keyboard-friendly controls, reduced-motion support, catalogue tests, CI type-check and production build.
