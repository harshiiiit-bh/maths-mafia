# Maths Mafia project rules

- Build an independent Class 10 CBSE Mathematics product.
- Do not use VAANI branding, characters, names, logos or assets.
- Current phase is frontend/UI only: no database, authentication, payments or live student data.
- Label all sample questions, scores, names, charts and learning activity as demo content.
- Real notes, questions and PYQs will be supplied later.
- Use Next.js App Router, React, TypeScript, Tailwind CSS and accessible responsive components.
- Keep components focused and reusable. Use Lucide icons.
- Inspect before changing. Do not delete working features without approval.
- Never expose secrets, commit environment files, force-push, create pull requests or deploy to production without explicit approval.
- Run tests, typecheck and production build before claiming completion.
