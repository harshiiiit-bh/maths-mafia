# Maths Mafia — project rules

## Identity
- Build an independent Class 10 Mathematics product.
- Never use VAANI branding, characters, names, logos or assets.

## Current phase: frontend and tools only
- Build UI/UX, responsive layouts, navigation and client-side features.
- Do not add educational notes, questions, worked examples, formulas, chapters, sample users, mock scores, seeded progress or other fixture content.
- No backend, database, authentication, payments, analytics or persistence.
- Calculator, plotter, timer and scratchpad may operate locally in the browser only. Do not send or persist user input.
- All content areas must use honest empty states until the owner supplies content.

## Engineering
- Next.js App Router, React, TypeScript, Tailwind CSS and Lucide React.
- Small reusable accessible components. Mobile, tablet, laptop and desktop support.
- No unsafe eval/new Function for expression evaluation.
- Keep user-input calculations bounded and handle invalid expressions.

## Git and safety
- Inspect before editing. Do not destroy working features without approval.
- Never expose secrets or commit environment files.
- Never create pull requests, force-push, or deploy to production without explicit approval.
- Never connect a new repository or overwrite a remote branch without approval.

## Quality
- Run tests, TypeScript checks and the production build before claiming completion.
- Test empty states, calculator parsing, invalid expressions and responsive interactions.
